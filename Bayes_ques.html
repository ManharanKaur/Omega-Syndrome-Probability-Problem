Problem Statement

A rare genetic condition, "Omega Syndrome," affects 0.01% of the population. Three genetic markers (A, B, and C) are associated with Omega Syndrome. Tests exist for each marker, but they have varying degrees of accuracy and dependency:

Marker A has a 95% sensitivity and 98% specificity.
Marker B's accuracy depends on whether marker A is present:

  • If A⁺ → B has 90% sensitivity, 95% specificity.
  • If A⁻ → B has 80% sensitivity, 99% specificity.
Marker C depends on both A and B:
  • If A⁺ and B⁺ → C: 98% sens, 90% spec
  • If A⁻ and B⁻ → C: 90% sens, 98% spec
  • All others → C: 95% sens, 95% spec
An individual tests A⁺, B⁻, and C⁺. What is the probability they have Omega Syndrome?

Solution Summary

Use Bayes’ Theorem:
Let E = event of testing A⁺, B⁻, C⁺. Compute:
P(Omega | E) = [P(E | Omega) * P(Omega)] / Total Probability

Compute all 4 full paths:
1. Omega → A⁺ → B⁻ → C⁺ → Prob = 0.0001 * 0.95 * 0.10 * 0.95
2. No Omega → A⁺ → B⁻ → C⁺ → Prob = 0.9999 * 0.02 * 0.95 * 0.05
Add up both to get denominator, use numerator from (1)
Final posterior probability ≈ 9.1%
